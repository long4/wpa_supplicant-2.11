Parameters for DWC_xlgpcs - 2.20a

These tables define all of the user configuration options for this component. Entries which are grayed-out are disabled (read-only) in the current configuration.

  • Features / System Configurations Settings
  • Features / PHY Interface

Features / System Configurations Settings Parameters

Table 1. Features / System Configurations Settings Parameters

LabelValueDescription
Mode of Operation25G

Configures the mode of operation of the DWC_xlgpcs.

  • 25G: RTL configuration supports 25G and 10G modes.
  • 25G-50G: RTL configuration supports 50G, 25G, and 10G modes. If 'Single-lane Only configuration' is not selected, the configuration additionally supports 40G mode.
  • 40G: RTL configuration supports 40G and 10G modes.
  • 100G: RTL configuration supports 100G, 50G, 40G, 25G, and 10G modes.

Values:

  • 25G (0)
  • 25G-50G (1)
  • 40G (2)
  • 100G (3)

DefaultValue: 40G

Enabled: Always

Parameter Name: DWCXLP_MAIN_MODE

Single-lane Only configuration1

Configures the RTL to a single-lane Only Configuration.

  • If 'Mode of Operation' is chosen as '25G-50G' and if this option is selected, the selected RTL configuration will be a single-lane configuration supporting 50Gx1 (PAM4), 25Gx1 (NRZ) and 10Gx1(NRZ) modes.
  • If 'Mode of Operation' is chosen as '100G' and if this option is selected, the selected RTL configuration will be a single-lane configuration supporting 100Gx1 (PAM4), 50Gx1 (PAM4), 25Gx1 (NRZ) and 10Gx1(NRZ) modes.

Values: 0, 1

DefaultValue: 1

Enabled: (DWCXLP_MAIN_MODE == 1)||(DWCXLP_MAIN_MODE == 3)

Parameter Name: DWCXLP_SINGLE_LANE

Values: 0, 1

DefaultValue: 0

Enabled: (DWCXLP_MAIN_MODE == 1||DWCXLP_MAIN_MODE == 3)&&!DWCXLP_SINGLE_LANE

Parameter Name: DWCXLP_PAM4

Add CL73 Autoneg Support1

Enable CL73 Auto-negotiation.

Values: 0, 1

DefaultValue: 1

Enabled: Always

Parameter Name: DWCXLP_CL73_AN

Support Alternate Autonegotiation flow0

Adds Support for Alternate Clause 73 Auto-negotiation flow. As per this alternate flow, AN is performed only once with serdes configured to 10G NRZ mode. Switch to the negotiated speed is initiated in AN_GOOD_CHECK state without restarting the auto-negotiation. If this parameter is enabled, vendor-specific parallel-detect feature will work only for 10G NRZ mode. If this parameter is not selected, the legacy auto-negotiation flow, which involves two rounds of auto-negotiation will be supported and the vendor-specific parallel-detect feature can work in all the supported modes. User selection of this parameter is not allowed if the chosen configuration has PAM4 support or MDIO interface or Link-training support.

Values: 0, 1

DefaultValue: 0

Enabled: !DWCXLP_PAM4&&DWCXLP_CL73_AN&&!DWCXLP_SNPS_XAUI_PHY&&!DWCXLP_MDIO_INTF

Parameter Name: DWCXLP_CL73_ALT

Add Timestamping Accuracy Support1

Enables support for IEEE802.3cx timestamping feature.

Values: 0, 1

DefaultValue: 0

Enabled: DWCXLP_25G_ONLY

Parameter Name: DWCXLP_TS_EN

Management InterfaceAPB3 Interface (32-bit register)

Specifies the serial Management Data Input/Output (MDIO) interface, or APB3 interface (3 types) with the Control and Status registers. For 'APB3 Interface (legacy)' interface, DWC_xlgpcs registers are 16-bit wide and addresses of registers are multiples of 1. This is the legacy APB3 interface supported till 2.10a. For 'APB3 Interface (16-bit register)' interface, DWC_xlgpcs registers are 16-bit wide but addresses of registers are multiples of 2. For 'APB3 Interface (32-bit register)' interface, DWC_xlgpcs registers are 32-bit wide but addresses of registers are multiples of 4.

Values:

  • MDIO Interface (0)
  • MicroController Interface (1)
  • APB3 Interface (legacy) (2)
  • APB3 Interface (16-bit register) (3)
  • APB3 Interface (32-bit register) (4)

DefaultValue: APB3 Interface (legacy)

Enabled: Always

Parameter Name: DWCXLP_CSR_INTERFACE

Enable Indirect Register Access1

Enables indirect access to registers in the DWC_xlgpcs. By default, each DWC_xlgpcs register is accessible through 21-bit/22-bit(APB_16)/23-bit(APB3_32) wide address. By enabling this mode, the upper 13-bit of the address can be written to a pre-defined register so that only 8-bit or 9-bit (APB_16) or 10-bit (APB3_32) address bus is used for all register accesses in the DWC_xlgpcs.

Values: 0, 1

DefaultValue: 1

Enabled: DWCXLP_CSR_INTERFACE!=0

Parameter Name: DWCXLP_INDIRECT_ACCESS

Add CL74 Forward Error Correction Support1

Enables the support for the CL74 Forward Error Correction (FEC) sub layer embedded in the PCS. This FEC can detect and correct single burst error up to 11 bits. This feature is useful for erroneous channel. The CL74 FEC will not be used in 100G Speed mode.

Values: 0, 1

DefaultValue: 0

Enabled: Always

Parameter Name: DWCXLP_FEC_EN

Add CL74 FEC Error Forwarding Support1

Enables the CL74 FEC block to forward error information to the Block Synchronization module. This option adds more design latency and hardware in the Receive path. When you enable this option, if there are uncorrectable errors, then the error reporting ability is accurate on the XLGMII receive interface.

Values: 0, 1

DefaultValue: 1

Enabled: DWCXLP_FEC_EN&&!DWCXLP_RSFEC_EN

Parameter Name: DWCXLP_FEC_ERROR_FWD

Add (528,514) RS FEC Error Correction Support1

Enables the support for the Reed-Solomon Forward Error Correction (FEC) RS(528,514) sub layer as per IEEE 802.3 clause-91/clause 108 embedded in the PCS for serial lane speeds at 25Gbps. This feature is not applicable for 10G/20G/40G mode of operation. RS-FEC Error-forwarding feature also gets added when you select this option

Values: 0, 1

DefaultValue: 0

Enabled: (DWCXLP_MAIN_MODE != 2)&&!(DWCXLP_50G_25G||DWCXLP_100G_1LANE)

Parameter Name: DWCXLP_RSFEC_EN

Enables the support for the Reed-Solomon Forward Error Correction (FEC) RS(544,514) sub layer along with Error-Forwarding Support. This feature is applicable for 100Gx1, 50Gx1 and 50Gx2 modes.

Values: 0, 1

DefaultValue: 0

Enabled: 0

Parameter Name: DWCXLP_RS544

Values: 0, 1

Parameter Name: DWCXLP_IRSFEC

Add per-lane XSBI Tx clock0

Enables Support for Separate XSBI Tx clock for each lane. This feature is enabled only if the SerDes does not take a transmit clock per-lane as input, but instead samples the input tx{lane} data with an internal per-lane clock. Note that, even though DWC_xlgpcs allows support of separate XSBI tx clock per-lane, it cannot tolerate any ppm difference in frequency between the various XSBI Tx clocks. It can only tolerate differences in jitter. Moreover, the internal datapath still operates with a single clk_rpcs_tx_i.

Features / MAC Interface Parameters

Table 3. Features / MAC Interface Parameters

LabelValueDescription
XLGMII interface data-width32

Specifies the data width of the MAC interface (xlgmii_txd_i and xlgmii_rxd_o) as 128-bit or 64-bit or 32-bit. This selection is available only for 25G_Only configurations. When the chosen option is '64', both 25G and 10G modes operate with 64-bit wide interface. When the chosen option is '32', both 25G and 10G modes operate with 32-bit wide interface. If the chosen option is '128', a 128-bit wide interface is used for all modes except 10G mode. In 10G mode, only lower 32-bits of the 128-bit interface will be active.

Values:

  • 128 (0)
  • 64 (1)
  • 32 (2)

DefaultValue: 128

Enabled: DWCXLP_MAIN_MODE == 0

Parameter Name: DWCXLP_XLGMII_INTF_WIDTH
