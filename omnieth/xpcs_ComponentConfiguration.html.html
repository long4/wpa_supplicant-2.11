Management InterfaceAPB3 Interface (32-bit register)

Specifies the parallel micro-controller interface (MCI), the serial Management Data Input/Output (MDIO) interface, or APB3 interface (3 types) with the Control and Status registers. For 'APB3 Interface (legacy)' interface, DWC_xpcs registers are 16-bit wide and addresses of registers are multiples of 1. This is the legacy APB3 interface supported till 3.30a. For 'APB3 Interface (16-bit register)' interface, DWC_xpcs registers are 16-bit wide but addresses of registers are multiples of 2. For 'APB3 Interface (32-bit register)' interface, DWC_xpcs registers are 32-bit wide but addresses of registers are multiples of 4.

Values:

  • MDIO Interface (0)
  • MicroController Interface (1)
  • APB3 Interface (legacy) (2)
  • APB3 Interface (16-bit register) (3)
  • APB3 Interface (32-bit register) (4)

DefaultValue: MDIO Interface

Enabled: Always

Parameter Name: CSR_INTERFACE

Enable Indirect Register Access1

Enables indirect access to registers in the DWC_xpcs. By default, each DWC_xpcs register is accessible through 21-bit/22-bit(APB3_16)/23-bit (APB3_32) wide address. By enabling this mode, the upper 13-bit of the address can be written to a pre-defined register so that only 8-bit or 9-bit (APB3_16) or 10-bit (APB3_32) address bus is used for all register accesses in the DWC_xpcs.

Values: 0, 1

DefaultValue: 0

Enabled: CSR_INTERFACE!=0

Parameter Name: INDIRECT_ACCESS

Add SGMII PHY Automate0

Support to automate the clause 37 SGMII auto-negotiation restart in PHY mode. When this option is enabled, additional input ports to indicate the speed (xpcs_sgmii_link_speed_i), duplex mode (xpcs_sgmii_full_duplex_i) and link-status (xpcs_sgmii_link_sts_i) of the network link gets added to DWC_xpcs controller. In this mode, any change to these input ports results in automatic re-triggering of SGMII auto-negotiation to convey the new speed/duplex mode/link-status to the MAC-side of the SGMII link. You can enable this option to use DWC_xpcs at PHY-side of the SGMII link and indicate the network link speed/status to DWC_xpcs using input ports (instead of Register programmed values).

Values: 0, 1

DefaultValue: 0

Enabled: SGMII_EN

Parameter Name: SGMII_PHY_AN_AUTO_RESTART

Add QSGMII PHY Automate0

In this mode, any change to these input ports results in automatic re-triggering of corresponding QSGMII auto-negotiation to convey the new speed/duplex mode/link-status to the corresponding MAC at the other side of the QSGMII link. You can enable this option to use DWC_xpcs at PHY-side of the QSGMII link and indicate the network link speed/status to DWC_xpcs using input ports (instead of Register programmed values).

Values: 0, 1

DefaultValue: 0

Enabled: QSGMII_EN

In this mode, any change to these input ports results in automatic re-triggering of corresponding USXGMII auto-negotiation to convey the new speed/duplex mode/link-status/EEE cap/EEE clock-stop cap to the corresponding MAC at the other side of the USXGMII link. You can enable this option to use DWC_xpcs at PHY-side of the USXGMII link and indicate the network link speed/status/EEE_cap/EEE_clk_stop_cap to DWC_xpcs using input ports (instead of Register programmed values).
