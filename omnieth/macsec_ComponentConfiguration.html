Parameters for DWC_macsec - 1.05a

These tables define all of the user configuration options for this component. Entries which are grayed-out are disabled (read-only) in the current configuration.

Selects the APB version and corresponding features to be supported. The following options can be selected:

  • DWC_MACSEC_APB_VER = 0 | "APB-4" : follows the AMBA APB Specification (Issue C), commonly referred to as APB-4.
  • DWC_MACSEC_APB_VER = 1 | "APB-5 RME" : follows the AMBA APB Specification (Issue E), adding only Realm Management Extension (RME) support.
  • DWC_MACSEC_APB_VER = 2 | "APB-5 Parity" : follows the AMBA APB Specification (Issue D), adding only parity protection and check signals.
  • DWC_MACSEC_APB_VER = 3 | "APB-5 RME Parity": follows the AMBA APB Specification (Issue E), adding only Realm Management Extension (RME) support and parity protection and check signals.

AES SBOX Architecture SelectionHigh-Speed Optimized

Select the architecture of the S-boxes used within the AES cores. Selecting high-speed architecture will offer better results for reaching high operating frequencies, but will increase the size of the IP. Selecting area optimized architecture will offer lower IP area footprint, but lower maximum operating frequency.

Values:

  • High-Speed Optimized (0)
  • Low-Area Optimized (1)

DefaultValue: Low-Area Optimized

Enabled: Always

Parameter Name: DWC_MACSEC_AES_SBOX_ARCH
